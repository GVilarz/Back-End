# O que é o DOM?

o **DOM (Document Object Model)** é a reoresentação do HTML em forma de **árvore de objetos**.

Isso permite que o JavaScript:

- Leia elementos da página
- Modifique textos
- Troque imagens
- Reaja a cliques
- Crie elementos novos

> O navegador transforma o HTML em objetos manipulaveis
